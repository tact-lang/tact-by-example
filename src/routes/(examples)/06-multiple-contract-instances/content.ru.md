# Несколько экземпляров контракта

Вместо того чтобы дублировать код для двух контрактов, как в предыдущем примере, мы можем написать код один раз и всё равно развернуть два отдельных экземпляра. Каждый экземпляр будет иметь свой уникальный адрес.

Для этого достаточно добавить аргумент в `init()`. При развёртывании контракта необходимо указать его аргументы инициализации. В этом примере мы развёртываем контракт дважды: первый раз с аргументом 1, а второй — с аргументом 2.

Ранее мы упоминали, что адреса контрактов в TON [вычисляются](https://docs.ton.org/learn/overviews/addresses#account-id) на основе начального кода контракта (скомпилированного байт-кода) и начальных данных контракта (аргументов init).

Поскольку код написан один раз, начальный код теперь идентичен. Добавив аргумент конструктора, мы сделали начальные данные различными. Именно поэтому мы получим два разных адреса.
