# Массивы

Вы можете реализовать простые массивы в Tact, используя тип `map`.

Чтобы создать массив, определите словарь (map) с типом `Int` в качестве ключа. Этот ключ будет представлять индекс в массиве. Дополнительно добавьте переменную для отслеживания количества элементов в массиве.

Пример контракта записывает последние пять временных меток, когда было получено сообщение `timer`. Эти временные метки хранятся в циклическом массиве, реализованном как словарь (map).

## Ограничение количества элементов

Словари (maps) предназначены для хранения ограниченного количества элементов. Используйте словарь только если вы знаете максимальное количество элементов, которое он будет содержать. Также рекомендуется [написать тест](https://github.com/tact-lang/tact-emulator), чтобы заполнить словарь максимальным количеством элементов и проверить, как ведёт себя потребление газа под нагрузкой.

Если количество элементов неограниченно и потенциально может вырасти до миллиардов, вам потребуется спроектировать контракт иначе. Мы обсудим неограниченные массивы позже в теме шардирования контрактов.
