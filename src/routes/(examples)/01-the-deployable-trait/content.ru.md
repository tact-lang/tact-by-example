# Трейт Deployable

Tact не поддерживает классическое наследование классов, но контракты могут реализовывать **_трейты_**.

Один из часто используемых трейтов — `Deployable`, который реализует простой ресивер для сообщения `Deploy`. Он помогает развёртывать контракты стандартизированным способом.

Все контракты развёртываются путём отправки им сообщения. Хотя для этого можно использовать любое сообщение, лучшей практикой является использование специального сообщения `Deploy`.

Это сообщение имеет одно поле `queryId`, которое задаётся инициатором развёртывания (обычно устанавливается в ноль). Если развёртывание прошло успешно, контракт ответит сообщением `DeployOk` и вернёт тот же `queryId` в ответе.

---

Если вы используете [автоматически сгенерированные](https://docs.tact-lang.org/ecosystem/tools/typescript#tact-contract-in-typescript) TypeScript-классы Tact для развёртывания, отправка сообщения deploy должна выглядеть так:

```ts
const msg = { $$type: "Deploy", queryId: 0n };
await contract.send(sender, { value: toNano(1) }, msg);
```

Вы можете посмотреть реализацию трейта [здесь](https://github.com/tact-lang/tact/blob/main/src/stdlib/stdlib/libs/deploy.tact). Обратите внимание, что файл **_deploy.tact_** необходимо импортировать из стандартной библиотеки с помощью ключевого слова `import`.
