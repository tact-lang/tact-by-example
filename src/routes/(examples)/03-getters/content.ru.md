# Геттеры

Геттеры — это специальные функции контракта, которые позволяют пользователям запрашивать информацию из контракта.

Все методы контракта, начинающиеся с префикса `get fun`, являются геттерами. Вы можете определить сколько угодно геттеров. Каждый геттер должен указывать тип возвращаемого значения — например, `counter()` возвращает `Int`.

Вызов геттеров бесплатен и не требует газа. Вызов выполняется полной нодой и не проходит через консенсус валидаторов и не добавляется в новый блок.

Геттеры доступны только для чтения — они не могут изменять персистентное состояние контракта.

Если убрать ключевое слово `get` из объявления функции геттера, она перестанет быть геттером. Внешние пользователи больше не смогут вызвать эту функцию, и она фактически станет приватным методом контракта.

## Геттеры между контрактами

**Контракт не может вызвать геттер другого контракта.**

Геттеры доступны только конечным пользователям вне блокчейна (off-chain). Поскольку контракты выполняются в блокчейне (on-chain), они не имеют доступа к геттерам друг друга.

Но если нельзя вызвать геттер, как два контракта могут взаимодействовать?

Единственный способ взаимодействия контрактов в блокчейне — отправка сообщений друг другу. Сообщения обрабатываются в _ресиверах_.

> **Info**: Блокчейн TON является асинхронным, что означает, что смарт-контракты могут взаимодействовать друг с другом только посредством отправки сообщений.
