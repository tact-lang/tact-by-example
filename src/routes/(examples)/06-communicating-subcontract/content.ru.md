# Взаимодействие с дочерними контрактами

При связи «родитель — потомок» пользователь обычно развёртывает только родительский контракт. Именно это происходит при нажатии кнопки <span class="mdButton blue">Deploy</span>.

В этом примере пользователь должен взаимодействовать только с родителем. Вы можете отправить родительскому контракту сообщение, нажав кнопку <span class="mdButton grape">Send greet 3</span>.

Это сообщение даст родителю команду отправить собственное сообщение `HiFromParent` первым 3 дочерним контрактам. Каждый потомок ответит на приветствие, отправив родителю собственное сообщение `HiFromChild`.

## Как родитель может узнать, развёрнут ли потомок?

Нельзя отправить сообщение контракту, который ещё не развёрнут. Как родитель может гарантировать, что он не обращается к ещё не развёрнутому потомку?

Лучшая практика — прикладывать *stateInit* к каждому сообщению. Таким образом, если потомок ещё не развёрнут, он будет развёрнут автоматически. Если потомок уже развёрнут, это поле будет проигнорировано.

Это называется ленивым развёртыванием (lazy deployment).
