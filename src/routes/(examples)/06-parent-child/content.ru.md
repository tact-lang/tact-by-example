# Связь «родитель — потомок»

Очень распространённый паттерн проектирования в Tact — реализация двух контрактов со связью «родитель — потомок».

В рамках этого паттерна обычно существует единственный экземпляр родительского контракта, который развёртывается пользователем. В данном примере это контракт `TodoParent`.

Дочерний контракт `TodoChild` будет иметь множество экземпляров. Эти экземпляры обычно развёртываются родителем при получении соответствующего сообщения.

Попробуйте сами. Нажмите кнопку <span class="mdButton grape">Send "deploy another" to parent</span> несколько раз, чтобы отправить сообщение родителю и дать ему команду развернуть всё больше дочерних контрактов.

Также обратите внимание, что мы можем не добавлять трейт `Deployable` дочерним контрактам. Этот трейт в основном полезен для контрактов, которые развёртывают пользователи. Поскольку пользователь развёртывает только родителя, отсутствие этого трейта у потомков явно выражает наше намерение для читателей кода.

## Неограниченные структуры данных

Интересное свойство этого паттерна — количество потенциальных потомков не ограничено! Мы можем иметь бесконечное число дочерних контрактов.

В целом бесконечные структуры данных, способные реально масштабироваться до миллиардов элементов, очень сложно эффективно реализовать в блокчейне. Этот паттерн демонстрирует мощь TON.
