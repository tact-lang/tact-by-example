# Простой счётчик

Это простой контракт-счётчик, позволяющий пользователям увеличивать его значение.

У этого контракта есть переменная состояния `val`, которая сохраняется между вызовами контракта — это значение счётчика. При сохранении эта переменная кодируется `as uint32` — как 32-битное беззнаковое целое число. Контракты платят ренту пропорционально объёму используемого постоянного хранилища, поэтому компактное представление данных приветствуется.

Переменные состояния должны быть инициализированы в `init()`, который выполняется при развёртывании контракта.

## Получение сообщений

Этот контракт может получать **_сообщения_** от пользователей.

В отличие от геттеров, которые работают только на чтение, сообщения могут выполнять операции записи и изменять постоянное состояние контракта. Входящие сообщения обрабатываются в методах `receive()` как транзакции, и отправитель платит за них газ.

После развёртывания контракта отправьте сообщение `increment`, нажав кнопку <span class="mdButton grape">Send increment</span>, чтобы увеличить значение счётчика на единицу. Затем вызовите геттер `value()`, чтобы убедиться, что значение действительно изменилось.
