# Словари (Maps)

Словари (maps) — это тип данных, который может хранить произвольное количество элементов, каждый под своим ключом.

Ключами в словарях могут быть типы `Int` или `Address`.

Вы можете проверить, есть ли ключ в словаре, вызвав метод `get()`. Он вернёт `null`, если ключ отсутствует, или значение, если ключ найден. Чтобы заменить значение по ключу, вызовите метод `set()`.

Целые числа в словарях, хранящихся в состоянии, в настоящее время используют максимальный размер целого числа (257 бит). Будущие версии Tact позволят оптимизировать размер кодирования.

## Ограничение количества элементов

Словари предназначены для хранения ограниченного количества элементов. Используйте словарь только если вы знаете верхнюю границу количества элементов, которые он может содержать. Также рекомендуется [написать тест](https://github.com/tact-lang/tact-emulator), чтобы добавить максимальное количество элементов в словарь и проверить, как ведёт себя потребление газа под нагрузкой.

Если количество элементов неограниченно и потенциально может вырасти до миллиардов, вам потребуется спроектировать контракт иначе. Мы обсудим неограниченные словари позже в теме шардирования контрактов.
