# Строки

Tact имеет базовую поддержку строк. Строки поддерживают юникод и не имеют специальных escape-символов вроде `\n`.

Использование строк в смарт-контрактах должно быть весьма ограниченным. Смарт-контракты — это точные программы для управления деньгами, они не предназначены для интерактивного CLI.

Строки неизменяемы (immutable). После создания последовательности символов её нельзя модифицировать.

Если вам нужна конкатенация строк во время выполнения, используйте `StringBuilder`. Этот объект эффективно расходует газ и поддерживает `append()` различных типов к строке.
