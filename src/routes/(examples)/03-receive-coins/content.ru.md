# Получение TON-монет

Каждый контракт имеет баланс в TON-монетах. Этот баланс используется для оплаты аренды хранилища и не должен обнуляться, иначе контракт может быть удалён. Вы можете хранить на балансе дополнительные монеты для любых целей.

Каждое входящее сообщение обычно несёт некоторое количество TON-монет, отправленных отправителем. Это значение используется для оплаты газа при обработке сообщения. Неиспользованный остаток останется на балансе контракта. Если значения не хватит для покрытия стоимости газа, транзакция будет откачена.

Вы можете запросить баланс контракта с помощью `myBalance()` — обратите внимание, что значение указывается в нано-тонах (как копейки, только с 9 десятичными знаками). Баланс уже включает значение из входящего сообщения.

## Возврат средств отправителю

Если транзакция откатывается, неиспользованный остаток будет отправлен обратно отправителю в _bounced_-сообщении.

Вы также можете вернуть остаток при успешной транзакции, отправив его обратно с помощью `self.reply()` в ответном сообщении. Это лучший способ гарантировать, что отправители платят только за тот газ, который фактически потребовало их сообщение.
