# Сообщения между контрактами

Разные контракты могут общаться друг с другом только через отправку сообщений. Этот пример демонстрирует два отдельных контракта, работающих в связке:

- `Counter` — простой счётчик, который может увеличиваться только на 1.
- `BulkAdder` — контракт, который указывает `Counter` увеличиться несколько раз.

Нажмите кнопку **Deploy**, чтобы развернуть оба контракта. Чтобы счётчик достиг 5, отправьте сообщение `Reach` контракту BulkAdder, нажав кнопку **Send Reach 5**.

Обратите внимание на количество сообщений, которыми обмениваются два контракта. Каждое сообщение обрабатывается как _отдельная_ транзакция. Также заметьте, что BulkAdder не может вызвать _геттер_ контракта Counter — вместо этого он должен отправить сообщение `query`.

## Кто платит за газ

**По умолчанию исходный отправитель отвечает за покрытие расходов на газ всей цепочки сообщений, которую он инициировал.** Это финансируется из исходного количества TON-монет, отправленных с первым сообщением `Reach`.

Внутренне это реализовано так, что каждый обработчик сообщения пересылает оставшийся неиспользованный остаток TON-монет в следующее отправляемое сообщение.

**Задание**: Попробуйте изменить код так, чтобы неиспользованный остаток газа возвращался исходному отправителю.
