# Условные операторы (if)

Tact поддерживает условные операторы `if` с синтаксисом, аналогичным большинству языков программирования, к которым вы привыкли. Однако фигурные скобки обязательны — их нельзя опускать.

Условие оператора может быть любым булевым выражением.

В Tact нет оператора `switch`. Если вам нужно обработать группу результатов по отдельности, используйте паттерн `else if`, как показано в третьем примере.
