# Генерация логов

Иногда полезно генерировать события из контракта, чтобы зафиксировать, что произошли определённые действия.

Эти данные впоследствии можно анализировать вне блокчейна и индексировать с помощью [RPC API](https://orbs.com/ton-access) для запроса всех транзакций, отправленных контракту.

Рассмотрим, например, стейкинг-контракт, который хочет фиксировать, сколько времени прошло до момента анстейкинга пользователями, для целей аналитики. Анализируя эти данные, разработчик может продумать улучшения продукта.

Один из способов реализации — отправка сообщений обратно отправителю с помощью `self.reply()` или отправка сообщений на нулевой адрес. Эти два метода работают, но они не самые эффективные с точки зрения расхода газа.

Функция `emit()` выводит сообщение (бинарное или текстовое) из контракта. Это сообщение фактически не имеет получателя и очень экономично по газу, поскольку его не нужно доставлять.

Сообщения, сгенерированные таким образом, всё равно записываются в блокчейн и могут быть проанализированы кем угодно в любое время.
