# Создание собственного трейта

Tact не поддерживает классическое наследование классов, а вместо этого вводит концепцию *трейтов*. Трейты похожи на упрощённые базовые классы, которые потенциально добавляют переменные состояния, ресиверы, геттеры или методы контракта.

Контракты могут использовать несколько трейтов. Выносите логику в трейт, если у вас есть несколько контрактов, которые разделяют эту логику.

## Трейт Trackable

Этот пример показывает, как написать новый трейт, добавляющий простое поведение аналитики к любому контракту.

Этот трейт также использует ключевое слово `virtual`, которое позволяет контракту, использующему трейт, переопределять некоторые его поведения. В примере поведение фильтра по умолчанию исключает сообщения от владельца из аналитики.

Контракт, использующий трейт, может изменить это поведение по умолчанию, указав ключевое слово `override` и предоставив новую реализацию этого метода. В нашем случае пользовательский фильтр означает отсутствие фильтров.
