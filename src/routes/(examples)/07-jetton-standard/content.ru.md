# Jetton-токен — взаимозаменяемые токены

Это пример общей реализации Jetton с нуля. Хотя мы не уделяли много внимания деталям Jetton Content, помните, что существует два способа реализации данных Jetton-токена, описанных в [TEP-64](https://github.com/ton-blockchain/TEPs/blob/master/text/0064-token-data-standard.md).

## Бесконечно масштабируемая карта балансов

В этом примере мы запускаем корневой Jetton-токен, использующий трейт `Jetton`, представленный ниже, с ограничением `max_supply` при развёртывании.

Процесс минтинга имеет два метода:

1. Отправить текстовое сообщение "Mint: 100" для выпуска токенов.
2. Отправить сообщение `Mint` с указанием `amount` для выпуска токенов.

### Закрытие функции минтинга

В этом примере реализована возможность отключения процесса минтинга. Для закрытия минтинга используется текстовое сообщение `Owner: MintClose`. Этот метод доступен только владельцу контракта.

## Перевод

Обратите внимание, что стандарт Jetton-токена также реализует метод `Transfer`, представленный ниже. Метод `Transfer` — самый важный метод в стандарте Jetton-токена, позволяющий переводить токены на другой аккаунт.
