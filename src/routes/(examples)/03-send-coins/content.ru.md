# Отправка TON-монет

Этот контракт позволяет выводить TON-монеты с его баланса. Обратите внимание, что это разрешено только тому, кто развернул контракт, — иначе средства могли бы быть украдены.

Выводимые средства отправляются как значение в исходящем сообщении отправителю. Рекомендуется явно устанавливать флаг `bounce` в `true` (хотя это и значение по умолчанию), чтобы в случае неудачи исходящего сообщения по любой причине средства вернулись на контракт.

Контракты должны иметь ненулевой баланс для периодической оплаты хранения, иначе они могут быть удалены. Этот контракт гарантирует, что на балансе всегда остаётся 0.01 TON, чего [достаточно](https://ton.org/docs/develop/smart-contracts/fees#storage-fee) для хранения 1 КБ состояния в течение 2,5 лет.

## Тонкости расчётов

`myBalance()` — это баланс контракта, включающий значение для газа, отправленное с входящим сообщением. `myBalance() - context().value` — баланс без значения для газа из входящего сообщения.

Режим отправки `SendRemainingValue` добавит к исходящему значению весь остаток от входящего сообщения после вычета всех расходов на газ.

Режим отправки `SendRemainingBalance` проигнорирует исходящее значение и отправит весь баланс контракта. Обратите внимание, что при этом на балансе не останется средств для оплаты хранения, и контракт может быть удалён.

> **Info**: Подробнее о различных режимах отправки можно узнать [здесь](https://docs.tact-lang.org/book/message-mode#combining-modes-with-flags)
